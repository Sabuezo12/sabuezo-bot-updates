# RinoBot / Helper 3.1.19

Esta version habilita las actualizaciones automaticas para el Helper.

## Una ultima instalacion manual

En 3.1.18 y versiones anteriores que muestran MANUAL, abre Actualizaciones, espera a que termine la verificacion, pulsa Actualizar a 3.1.19 y luego Recargar bot. Despues, el Updater comprueba al arrancar y cada cinco minutos con el Helper activo. Cuando haya una version nueva, descarga los archivos necesarios, instala y recarga automaticamente.

Se conservan los perfiles, rutas, preferencias y archivos personalizados protegidos. Siguen activos el respaldo, la recuperacion y la proteccion de copias de desarrollo o piloto.
